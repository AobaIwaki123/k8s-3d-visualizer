# 要件定義書

## プロジェクト概要

自宅KubernetesクラスターのNode・Pod・Service・Namespaceの構成とネットワーク接続を、Three.jsによる3Dグラフィクスでリアルタイム可視化するWebアプリケーション。

---

## 機能要件

### FR-01: クラスター情報の取得と表示

| ID | 機能 | 詳細 |
|---|---|---|
| FR-01-1 | Node表示 | クラスター内の全Nodeを3Dオブジェクトとして表示 |
| FR-01-2 | Pod表示 | 各Node上のPodを小さな3Dオブジェクトとして表示（Nodeの子として配置） |
| FR-01-3 | Namespace表示 | Namespaceをバブル/ゾーンとして視覚的に分離 |
| FR-01-4 | Service表示 | Serviceを光る接続ポイントとして表示 |
| FR-01-5 | Deployment表示 | Deploymentとそれが管理するPod群を関連付けて表示 |
| FR-01-6 | ネットワーク接続線 | ServiceとPod間の接続をアニメーション付き線で表示 |

### FR-02: リアルタイム更新

| ID | 機能 | 詳細 |
|---|---|---|
| FR-02-1 | Pod状態変化の反映 | Pod追加・削除・状態変化をリアルタイムで描画に反映 |
| FR-02-2 | 色による状態表示 | Running=緑, Pending=黄, Failed=赤, Terminating=グレー |
| FR-02-3 | 更新間隔 | WebSocketでプッシュ通知（変化があったときのみ） |

### FR-03: インタラクション

| ID | 機能 | 詳細 |
|---|---|---|
| FR-03-1 | カメラ操作 | ドラッグで回転、スクロールでズーム、右クリックでパン |
| FR-03-2 | オブジェクト選択 | Pod・Node・Serviceをクリックで詳細パネル表示 |
| FR-03-3 | 詳細情報表示 | 選択オブジェクトのラベル・アノテーション・ステータス・IP等を表示 |
| FR-03-4 | Namespace絞り込み | UIパネルでNamespaceのON/OFFフィルター |

### FR-04: 3Dモデルと演出

| ID | 機能 | 詳細 |
|---|---|---|
| FR-04-1 | Nodeモデル | Blender + Claude Blender Connectorで生成したGLBモデル（サーバーラック風） |
| FR-04-2 | Podモデル | 小さなキューブまたは球体（GLBまたはプロシージャル生成） |
| FR-04-3 | 通信アニメーション | Service間通信をパーティクル/光の粒が流れるアニメーションで表現 |
| FR-04-4 | 環境演出 | 宇宙・サーバールーム風の背景 |

---

## 非機能要件

| ID | 項目 | 要件 |
|---|---|---|
| NFR-01 | パフォーマンス | 60fps維持（Pod数100以下の想定） |
| NFR-02 | ブラウザ対応 | Chrome最新版（個人利用のため1ブラウザでOK） |
| NFR-03 | デプロイ先 | 自宅k8sクラスター内（外部公開なし） |
| NFR-04 | 可用性 | 自宅インフラなのでダウンタイム許容 |

## 対象Kubernetesリソース

初期実装で取得・表示するリソース：

- `nodes`
- `namespaces`
- `pods`
- `services`
- `deployments`
- `replicasets`

将来拡張候補：

- `ingresses`
- `configmaps`
- `persistentvolumeclaims`
- `events`（ログ表示）
