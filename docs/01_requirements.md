# 要件定義書

## プロジェクト概要

自宅KubernetesクラスターのNode・Pod・Service・Namespaceの構成とネットワーク接続を、Three.jsによる3Dグラフィクスでリアルタイム可視化するWebアプリケーション。

---

## 機能要件

### FR-01: クラスター情報の取得と表示

| ID | 機能 | 詳細 |
|---|---|---|
| FR-01-1 | Node表示 | クラスター内の物理Nodeを可視化（現在はPod配置の基準として機能） |
| FR-01-2 | Namespace可視化 | PodをNamespaceごとに地面の「Zone Plane（平面）」でグループ化して表示 |
| FR-01-3 | Pod/Service表示 | 稼働中のPodおよびServiceを3Dモデルとして表示 |
| FR-01-4 | 階層構造 | インフラ（Storage）、ワークロード、外部流入（Ingress）を垂直方向のレイヤーで分離 |

### FR-02: リアルタイム更新（予定）

| ID | 機能 | 詳細 |
|---|---|---|
| FR-02-1 | 状態同期 | クラスター内のリソース変更をWebSocket経由で画面に即座に反映 |

### FR-03: インタラクション

| ID | 機能 | 詳細 |
|---|---|---|
| FR-03-1 | Namespaceフォーカス | 特定のNamespaceを選択し、関連リソース以外を非表示にする |
| FR-03-2 | 情報インスペクタ | オブジェクトクリックで詳細情報をサイドパネルに表示 |
| FR-03-3 | カメラ制御 | ズーム、回転、およびNamespace選択時の自動追従（fitCamera） |

### FR-04: 特殊リソースの演出

| ID | 機能 | 詳細 |
|---|---|---|
| FR-04-1 | Storage Bedrock | Rook-Ceph等を地下に配置し、アプリからのPVC接続を垂直ラインで可視化 |
| FR-04-2 | Ingress Gateway | Cloudflare等の外部流入を上空のポータルとして可視化（オプトアウト可能） |
| FR-04-3 | 監視網可視化 | Beyla/Prometheus等の監視パルスを「光の網」として可視化（オプトアウト可能） |

---

## 視覚的メタデータ

Podの状態や役割に応じて、以下の視覚的変化を付与する。

- **Status**: Running (緑), Pending (黄), Failed (赤)
- **Role**: DB系は横に太く、API系は縦に細長いモデルスケール
- **Warning**: `restartCount > 0` の場合にマゼンタ色で発光
