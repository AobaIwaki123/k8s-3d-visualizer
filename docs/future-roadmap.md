# 今後の拡張予定・ロードマップ (Future Roadmap)

本ドキュメントは、k8s-3d-visualizer の将来的な機能拡張案および未実装の改善項目をまとめたものである。

## 1. UI/UX 改善案

### タイムライン・ヒストリー再生 (Timeline Playback)
- **目的**: 障害発生時の前後関係の把握やローリングアップデートの挙動可視化。
- **UI**: 画面下部のスライダーで過去の状態に遡り、Pod の増減をアニメーション表示。
- **技術要件**: `cluster-state.json` の履歴保持、差分更新ロジック。

### ステータス・ポップオーバー (Status Popover)
- **目的**: 統計エリアから異常 Pod へ即座にフォーカス。
- **UI**: 右上の統計テキストクリックで内訳を表示し、異常 Pod 名クリックでズーム。
- **技術要件**: `fitCamera` との連携。

### リソース・ミニバー (Resource Mini-bars)
- **目的**: CPU/メモリ使用率を 3D 空間の邪魔にならない形で常時表示。
- **UI**: トップバー付近に細身のプログレスバー（CPU: シアン, Memory: パープル）。
- **技術要件**: データ抽出スクリプトの拡張、Node Capacity/Usage の集計。

## 2. 機能拡張

### 監視網 (Observability) の完全可視化
- **目的**: Beyla/Prometheus 等の監視パルスを「光の網」として描画。
- **状況**: 現在は視認性確保のため描画スキップ（オプトアウト中）。

### 外部流入 (Ingress) のポータル演出強化
- **目的**: Cloudflare 等の外部流入を上空のポータルとしてより詳細に可視化。
- **状況**: 現在は機能オプトアウト中。

## 3. 実装上の課題 (Backlog)
- **データ永続化**: 現在のスナップショット方式から時系列データベースへの移行。
- **大規模環境への最適化**: Pod 数が数百を超えた場合のレンダリング負荷軽減（InstancedMesh の活用など）。
- **モバイル対応**: タッチ操作によるカメラ制御の最適化。
